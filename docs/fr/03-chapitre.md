# 3. États de transfert

Le token prévoit plusieurs états : désactivé, whitelisté ou pleinement actif. Les transitions et les listes noire/blanche déterminent qui peut transférer, frapper ou brûler.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
