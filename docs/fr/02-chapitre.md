# 2. Minting par ordre signé

Le module consomme des ordres signés et vérifie les autorisations avant de déplacer le collatéral. La séparation entre signature, whitelist et règlement est centrale.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
