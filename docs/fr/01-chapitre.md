# 1. Périmètre des contrats

Ce dépôt d’audit isole les contrats USDtb et leur contrôle d’accès. Le parcours distingue le token, le module de minting et les bibliothèques OpenZeppelin utilisées.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
