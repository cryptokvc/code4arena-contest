# 4. Administration et limites

L’administrateur peut modifier des paramètres puissants. Le code doit être lu avec le périmètre d’audit, les invariants de transfert et les dépendances de gouvernance.

Les noms de contrats, fonctions et fichiers sont à confronter directement au dépôt ; ce texte décrit le rôle architectural observé, sans certifier un déploiement ni un audit.
